# Listening edition

This folder is a parallel, rewritten version of the documents in
[`docs/`](../docs/) that most benefit from being heard rather than read —
the ones with real narrative content, as opposed to the reference tables
and file-path indexes that make up most of `docs/`.

These aren't transcripts. Each one is written fresh for the ear:
conversational sentences, no bullet lists, abbreviations expanded the
first time they're said, context before detail. If a fact here and a fact
in `docs/` ever disagree, `docs/` wins — this is a listening companion,
not a second source of truth. When the underlying system changes, update
`docs/` first and treat these as needing a re-listen-through, not an
automatic sync.

What's here:

- [`getting-started.md`](getting-started.md) — what groundtruth is and why
  it exists, narrated. The listening equivalent of the root README.
- [`architecture-overview.md`](architecture-overview.md) — how the pieces
  fit together, without the Mermaid diagrams (those don't survive being
  read aloud — this describes the same flow in words).
- [`adr-summary.md`](adr-summary.md) — a walk through the five
  architecture decisions in `docs/adr/`, as one continuous episode rather
  than five formal records.

Not every document gets a listening edition — the naming-conventions doc,
the glossary, and the feature reference table are exactly as useful read
as skimmed, and a narrated version of a table just re-adds the bullet
points it's trying to avoid. Add one here when a `docs/` document has
enough narrative shape to be worth hearing, not by default.
