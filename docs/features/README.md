# Features

> **Summary:** Two user-facing capabilities exist today: the `check`
> command, and the GitHub Action that runs it on a pull request.

- [`check-command.md`](check-command.md) — `groundtruth check`, the only
  command groundtruth has.
- [`github-action.md`](github-action.md) — the Action that runs that
  command in CI and reports into the pull request diff.

One doc per feature, added as features ship. Do not add a doc for a
roadmap item before it exists — see the root
[README § Roadmap](../../README.md#roadmap) for what's planned.
